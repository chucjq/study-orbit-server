Subjects

A subject groups decks, for example "Biology" or "Spanish". Subject names are unique regardless of case, and a subject cannot be deleted while it still has decks. Endpoints 1 to 5 in the index belong to this page.

Fields​

FieldTypeRulesDefault
namestringTrimmed, 2 to 40 characters, unique (case-insensitive)Required
colorstringSix-digit hex such as #22c55e#6366f1
iconstringUp to 4 characters; an empty string clears itnone

The response adds _id, deckCount, createdAt and updatedAt. deckCount includes archived decks.

GET /api/subjects​

Lists subjects with their deck counts.

QueryTypeDefaultNotes
searchstringnoneNarrows the list by name.
sortname or createdAtnameSort order.
pageinteger1Starts at 1.
limitinteger100Maximum 100.
curl -s "http://localhost:5000/api/subjects?search=bio&sort=name"
{
  "data": [
    {
      "_id": "6650a1f0c2e4b8d1a0000001",
      "name": "Biology",
      "color": "#22c55e",
      "icon": "🧬",
      "deckCount": 2,
      "createdAt": "2026-06-01T09:00:00.000Z",
      "updatedAt": "2026-06-01T09:00:00.000Z"
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 100
}

GET /api/subjects/:id​

Returns one subject in the same shape as a list item.

StatusMessage
400Invalid ID
404Subject not found

POST /api/subjects​

Creates a subject and returns it with status 201 and deckCount: 0.

curl -s -X POST http://localhost:5000/api/subjects \
  -H "Content-Type: application/json" \
  -d '{"name":"Biology","color":"#22c55e","icon":"🧬"}'
StatusMessage (example)
400name: Too small: expected string to have >=2 characters
400Duplicate value for: name when a subject with the same name exists
400Unknown field: <name>

PUT /api/subjects/:id​

Replaces the editable fields. An omitted color resets to #6366f1, and an omitted icon is cleared. Send the full object each time. Returns 200 with the updated subject, or 404 if it does not exist.

DELETE /api/subjects/:id​

Deletes a subject that has no decks. Returns 200 with { "message": "Subject deleted" }.

StatusMessage
400Cannot delete a subject that still has decks
404Subject not found

Delete the subject's decks first, which also removes their cards, reviews and sessions. See Decks.
